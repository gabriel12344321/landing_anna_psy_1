## 1. Команды Анны

### "На сегодня Всё"
Означает: сохранить контрольную точку.
Действия:
1. Сохранить все изменения в файлы
2. Закоммитить в Git с понятным описанием
3. Запушить на GitHub
4. Обновить лог проекта (docs/project_log.md)
5. Записать краткое содержание диалога в docs/chats/ (формат: chat_ГГГГ-ММ-ДД.md)
6. Сайт готов к продолжению работы в любой момент

Анна может вернуться к работе в тот же день. Это не конец, это сохранение.

Файлы чатов содержат: краткое содержание сессии, что обсуждали, 
какие решения приняли, что осталось. НЕ дословная копия — а сжатый конспект.

## 2. Версионирование

- Каждый файл в src/ содержит комментарий с номером версии и ТЗ
- Формат: "Версия: 2.0 (по ТЗ v2.0)"
- При обновлении по новому ТЗ — версия меняется во всех файлах
- Промты хранятся с версиями: promt_landing_v1.0.md, promt_landing_v2.0.md

---

## 3. Git: правила коммитов

Формат сообщений:
```
[тег] Краткое описание

Подробности если нужны.

Co-Authored-By: Claude Opus 4.6 (1M context) <noreply@anthropic.com>
```

Теги:
- [дизайн] — визуальные изменения
- [текст] — изменения в контенте
- [безопасность] — CSP, политика, заголовки
- [seo] — Schema.org, мета-теги, sitemap
- [фикс] — исправление багов
- [структура] — изменение архитектуры файлов
- [шрифты] — изменение шрифтов

---

## 4. Git: ветки

```
main        ← стабильная версия, только проверенное
└── dev     ← рабочая ветка (когда начнём использовать)
```

Пока работаем в main. При усложнении — перейдём на ветки.

## 11. Дизайн: утверждённые решения

- Стиль: тёплый минимализм, премиальный
- Палитра: #faf6f2, #f5ede6, #2c2120, #c4907a, #3b3231, #4a3c36
- Заголовки: Playfair Display (засечки)
- Текст: DM Sans (без засечек, как Apple) — утверждено 11.04.2026
- Отклонены: Nunito (простой), Cormorant Garamond (мелкий)
- Hero: split layout (текст слева, фото справа)
- Кружочек в hero — отклонён, не премиально
- Контейнер: 900-1000px на десктопе
- Отступы секций: 110px на десктопе

---

## 12. Контент: утверждённые решения

- ЦА: русскоязычные женщины 28-38 лет по всему миру
- Структура: 13 блоков (утверждена в ТЗ v2.0)
- CTA: "Написать Анне" (не "Записаться")
- Тон: тёплый, личный, без канцелярита
- Каналы связи: Telegram, ВКонтакте, Max, телефон
- Сайт в зоне .ru на российском хостинге

---

## 13. Безопасность: утверждённые решения

- 14 пунктов безопасности (утверждены Анной)
- Шрифты: только локальные (не Google Fonts)
- CSP: через мета-тег
- Cookie-баннер: обязателен перед Яндекс.Метрикой
- Политика конфиденциальности: privacy.html (152-ФЗ)
- Хостинг: российский + Cloudflare CDN
